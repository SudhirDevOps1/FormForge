⚙️ Form Settings & Integration Guide

Understand how to configure FormForge features directly in your dashboard.

🤖 Cloudflare Turnstile Verification

Protect your endpoints from automated bots using Cloudflare Turnstile's invisible CAPTCHA checks.

1
Get Turnstile Keys

Go to Cloudflare Dashboard -> Turnstile -> Click Add site. Enter your domain, choose Managed challenge, and click Create.

2
Configure Secret Key

Copy the **Secret Key** and paste it into the **Turnstile Secret Key** input field in FormForge settings, then save.

3
Add Script to Website

Embed Cloudflare's script tag <script src="https://challenges.cloudflare.com/turnstile/v0/api.js" async defer></script> in your website HTML.

📧 Submitter Autoresponder Email

Automatically send styled thank-you emails back to users when they submit forms.

1
Verify Resend Sender

Ensure your domain is configured in Resend.com and add the variables RESEND_API_KEY and RESEND_FROM to your Cloudflare Worker settings.

2
Setup Subject & Body

Draft your custom Autoresponder Subject and Body in FormForge. Use dynamic placeholder formatting to personalize the content.

3
Dynamic Variables

Use curly braces like {name}, {email}, or {message} in your body text. The backend dynamically replaces these with submitter data at runtime!

🚀 Ready to Deploy to Cloudflare Pages?

1

Connect GitHub

Go to Cloudflare Dashboard Workers & Pages -> Click Connect to Git and authorize the repository.

2

Configure Build Settings

Select Next.js framework preset. The build command will auto-run our custom build-cf.js loop protection script safely.

3

Add DB Binding

Bind a Cloudflare D1 database named DB under the Pages project settings -> Functions -> D1 Database bindings.
