# Changelog

The changelog for FormForge lives in **[`docs/CHANGELOG.md`](./docs/CHANGELOG.md)**.

That file is the single, machine-maintained record: `release-please` appends a
dated section for every release from the merged Conventional Commits, and the
`Release` workflow extracts the matching section to build the GitHub Release
notes. This root file exists only so that readers who expect a changelog at the
repository root are pointed at the real one instead of a stale copy.
