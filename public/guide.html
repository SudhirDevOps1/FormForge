🔑 AUTH_SECRET — What It Is & How to Set It

AUTH_SECRET is a secret key used to secure sessions and API keys. It is required. Without it, you cannot create an account.

⚠️ If you left it blank during deploy → fix it now:
1

Run this in your terminal:

bash 
openssl rand -hex 32
2

Go to Cloudflare Dashboard → Workers & Pages → click your Worker.

3

Navigate to Settings → Variables & Secrets → Add variable → select Secret.

4

Name: AUTH_SECRET, Value: paste the secret from your terminal. Click Save.

5

Redeploy the Worker, then reload the dashboard. You can now register.

🛠 Manual Deploy (via CLI)

If you prefer the command line instead of the one-click button:

bash 
# 1. Clone & install
git clone https://github.com/SudhirDevOps1/FormForge.git
cd FormForge
npm install

# 2. Login to Cloudflare
npx wrangler login

# 3. Auto setup (interactive)
npm run setup

# OR do it manually:
# 3a. Create D1 database
npx wrangler d1 create formforge-db
# Copy the database_id and paste it in wrangler.jsonc

# 3b. Set AUTH_SECRET
npx wrangler secret put AUTH_SECRET
# Paste your generated secret

# 3c. Deploy
npm run deploy
D1 auto-provisions. Migrations are optional because the app creates the schema on the first request.

🌍 Environment Variables

Name Required? Description
AUTH_SECRET YES Output of openssl rand -hex 32. Used for HMAC session/API-key hashing.
RESEND_API_KEY Optional Free API key from resend.com. Leave blank to disable email.
RESEND_FROM Optional Sender address. Example: FormForge <forms@example.com>
DB YES D1 binding name — already set in wrangler.jsonc. Not a secret.
⚠️ Important: Do not set DATABASE_URL. FormForge uses Cloudflare D1, not PostgreSQL. The D1 binding is all you need.

📊 Dashboard Guide

After deployment, visit /dashboard. Here's what you can do:

  • Forms tab: Click + New to create a form, search, select. Each form has its own endpoint, settings, and spam rules.
  • Submissions: Expand rows, view JSON, check status (accepted/spam), see time-ago timestamps.
  • Interactive Charts: View timeline charts showing submission trends over time.
  • Settings tab: Configure form name, URL slug, allowed origins, honeypot, webhooks, email, Turnstile, spam words, email verification (double opt-in), and data retention.
  • Multi-Format Export: Download all submissions in CSV, JSON, or TXT report formats — no vendor lock-in.
  • API Keys: Create read-only tokens for programmatic access. Set expiration dates.
  • HTML Snippets: Copy ready-to-use HTML form code for your website.
  • Hard Delete: Safely hard-delete forms and submissions from your SQLite D1 database.

🔒 Privacy & Security

FormForge treats security as a first-class citizen — these are enterprise-grade features:

🔐 Data Ownership
Your data stays in your Cloudflare D1. No third-party access.
🧮 Hashed IPs
IP addresses are SHA-256 hashed before storage. Raw IPs are never saved.
🔑 PBKDF2 Passwords
Passwords are hashed with PBKDF2-SHA256 (210K iterations). Brute force is nearly impossible.
🎫 HMAC Sessions
Session tokens are HMAC-SHA256 hashed. Secure cookies enabled.
🚫 No Tracking
No third-party analytics or tracking. No ad cookies.
📧 Optional Integrations
Email and webhooks are optional and off by default. You control everything.

🛡️ Advanced Features

These features are typically behind paid enterprise tiers in commercial form backends — all free in FormForge:

🤖 Cloudflare Turnstile Verification

Integrate Cloudflare's non-intrusive CAPTCHA to verify human submitters. Obtain a Site Key and Secret Key from the Cloudflare Turnstile dashboard. Save the secret key in form settings, and add the Turnstile widget to your HTML frontend.

📧 Custom Submitter Autoresponder

Automatically send personalized emails after form submission. Use {curly_braces} for dynamic field replacement. Example: Hi {name}, thank you for writing about {subject}!

🚫 Custom Spam Words Blocklist

Enter comma-separated keywords in form settings (e.g., crypto, casino, free money). If any field contains these words, the submission gets +100 spam score and is blocked.

🔑 API Key Expiration & Security

Generate secure API keys for programmatic access. Set expiration: 30, 90, 365 days, or Never. Expired keys return 401 Unauthorized.

💬 Slack & Discord Auto-Formatting Webhooks

Just paste your webhook URL. The backend automatically formats Slack blocks or Discord embedded cards with all submission details.

🗑️ Automatic Data Retention Purging

Keep your D1 storage clean. Set per-form retention: 30, 60, 90 days, or Keep Forever. Old records auto-delete on new submissions. Zero cron configuration needed.

🔌 API Examples

Register Owner Account

bash 
curl -X POST https://YOUR-WORKER.workers.dev/api/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"owner@example.com","name":"Owner","password":"change-this-password"}'

Create a Form

bash 
curl -X POST https://YOUR-WORKER.workers.dev/api/forms \
  -H 'Content-Type: application/json' \
  -b cookies.txt -c cookies.txt \
  -d '{"name":"Contact","allowedOrigins":"https://example.com"}'

Use in HTML

html 
<form method="POST" action="https://YOUR-WORKER.workers.dev/api/submit/endpoint_xxx">
  <input name="email" type="email" required />
  <textarea name="message" required></textarea>
  <!-- Honeypot spam trap -->
  <input name="website" tabindex="-1" autocomplete="off" hidden />
  <button>Send</button>
</form>

Use with fetch (JavaScript)

javascript 
await fetch("https://YOUR-WORKER.workers.dev/api/submit/endpoint_xxx", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ email: "hello@example.com", message: "Hi" }),
});

🐛 Troubleshooting

"Set AUTH_SECRET before creating accounts"

Solution: Set AUTH_SECRET in Cloudflare secrets and redeploy. No authentication works without it.

"Network error. Is the Worker deployed and D1 bound?"

Check these 3 things:

  1. Is the Worker deployed? Run npm run deploy or click deploy again.
  2. Is the D1 database created? Check Cloudflare Dashboard → Storage & Databases → D1.
  3. Is database_id in wrangler.jsonc correct? Leave it blank — Cloudflare auto-creates it.

"Error: DATABASE_URL is required"

Old PostgreSQL code is being imported. FormForge uses drizzle-orm/d1, not pg. Do not set DATABASE_URL. The D1 binding is sufficient.

"D1 binding not found" / "D1_NOT_CONFIGURED"

Cloudflare Dashboard → Worker → Settings → Bindings → Bind the D1 database formforge-db. The binding name must be exactly DB.

Deploy loop or build failure

Keep database_id blank in wrangler.jsonc. The Cloudflare deploy button auto-creates D1. For manual setup, run npx wrangler d1 create formforge-db.

❓ Frequently Asked Questions

Do I need a credit card?

No. Cloudflare's free tier doesn't require a credit card. FormForge is completely free.

Can I use a custom domain?

Yes. Cloudflare Dashboard → Worker → Custom Domains → add your domain.

Can I have forms for multiple websites?

Yes. Create unlimited forms. Each form has its own endpoint, origin allowlist, and settings.

What are the free tier limits?

100K requests/day, 5 GB D1 storage — can handle millions of submissions.

How do I export my data?

Use the CSV Export button in the dashboard. You can also use API keys for programmatic access.
