Core Features

Engineered specifically to solve the hurdles of modern single-page applications and static JAMstack architectures while keeping complete database sovereignty.

  • Action-URL Submission: Submit standard HTML forms with a clean action="/api/submit/{formId}".
  • JSON-over-Fetch Support: Submit structured JSON objects natively via asynchronous endpoints.
  • Strict Origin Filtering (CORS): Enforce origin whitelists right from your dashboard to stop external automated spam networks.
  • Smart Honeypot Spam Trap: An invisible field traps automated bots and successfully rejects them before database writes occur.
  • Cloudflare D1 Storage: All entries persist into your personal Cloudflare D1 SQLite database.
  • Resend Alerting: Dispatch transactional emails instantly upon ingestion.

System Architecture

FormForge is custom-built on top of the lightning-fast Cloudflare Serverless Network. Designed for incredible global reliability with zero cold starts:

Cloudflare Workers

Runs directly inside Edge isolates globally. Delivers sub-10ms operational response latency.

Cloudflare D1

Enterprise-grade SQLite storage. Fully relational with instant automated backups.

Drizzle ORM

Highly performant type-safe SQLite query engine tailored for Edge execution isolates.

One-Click Cloudflare Deployment

No software installation required. You can provision, build, and publish your private high-performance form backend in less than 2 minutes:

  1. Click the official Deploy to Cloudflare button at the top to launch the deployment assistant.
  2. Sign in with your private Cloudflare account. The generated worker function and database belong 100% to you.
  3. Choose a project name. Cloudflare automatically provisions your formforge-db D1 instance.
  4. Configure a secure AUTH_SECRET environment variable using the key generator below.
  5. Open your deployed worker hostname to initialize administrative access!
🔑

Environment Variables Reference

Configure secret properties and bindings directly inside your Cloudflare panel or your local configuration file:

Secret Variable Requirement Purpose
AUTH_SECRET Required A secure 32+ character key. Essential for signing JWT dashboard session tokens.
DB Required The Cloudflare D1 Database binding pointer linking code to the SQLite D1 layer.
RESEND_API_KEY Optional Your secure Resend.com API key to enable email alerts on submissions.

API Integration Code

1. Standard HTML Form (No JS)

<form action="https://your-domain.workers.dev/api/submit/contact_form_82c1" method="POST">
  <!-- Honeypot anti-spam protection (Invisible field) -->
  <input type="text" name="_honeypot" style="display: none;" />

  <input type="email" name="email" required placeholder="Enter email" />
  <textarea name="message" required placeholder="Message"></textarea>
  <button type="submit">Submit Form</button>
</form>

2. Asynchronous Fetch Submission

const submitData = async (payload) => {
  const response = await fetch("https://your-domain.workers.dev/api/submit/contact-form", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload)
  });
  const data = await response.json();
  if (data.ok) {
    console.log("Submission successful:", data.data);
  }
};

Privacy & GDPR

FormForge is designed with privacy as a first-class citizen. Unlike commercial form providers, you run the database under your own Cloudflare account. No third-party tracks or accesses your user's inputs.

GDPR Compliance: FormForge supports strict CORS origin filtering, customizable client IP tracking controls, and complete control over data removal to assist with GDPR deletion requests.

Troubleshooting FAQ

Q: Why do I get a CORS error on form submission?

A: Ensure you have whitelisted the origin domain in your dashboard settings for the specific form.

Q: How do I change the redirect URL after an HTML form is submitted?

A: You can configure the `Redirect URL` property inside the visual settings dashboard for the respective form.
