Architecture

Why FormForge?

Inspired by simplicity, upgraded for a modern Cloudflare-native stack.

🔓 No Paid Database Required

No PostgreSQL pool initialization at build time. Uses Cloudflare D1 (free-tier friendly SQLite) built directly into Workers. No DATABASE_URL build failures.

⚡ OpenNext + Cloudflare Workers

Built with @opennextjs/cloudflare for seamless Next.js 16 deployment to Cloudflare Workers. Deploys fast, runs serverless.

🔒 Privacy First

Data stays in your Cloudflare account. IP addresses are hashed per form. Secure cookies, HMAC-hashed sessions, PBKDF2 password hashes, and API key expiration.

♾️ No Artificial SaaS Limits

Your limits are your Cloudflare plan and D1 quotas — not artificial paywall restrictions. 100,000 writes/day on the free tier. Unlimited forms, unlimited endpoints.

Enterprise-Grade

🛡️ Advanced Security & Premium Features

Features typically behind paid enterprise tiers — available free and open-source.

🛡️ ALTCHA Proof-of-Work Anti-Spam

100% free, self-hosted, privacy-first spam protection. Replaces intrusive third-party CAPTCHAs with silent in-browser cryptographic Proof-of-Work challenges. Zero cookies, GDPR-compliant, and no external API keys required.

1
Enable in Form Settings

Open form settings in FormForge, toggle on ALTCHA Proof-of-Work Anti-Spam, and save your form.

2
Add Script to Website

Include the lightweight official ALTCHA web-component script in your site header:

<script defer src="https://cdn.jsdelivr.net/npm/altcha/dist/altcha.min.js" type="module"></script>
3
Add Widget to Your Form

Place the widget tag inside your form with your form's challenge URL:

<altcha-widget challengeurl="/api/altcha/challenge"></altcha-widget>

📧 Custom Submitter Autoresponder

Automatically deliver structured, personalized emails to users immediately after they submit a form.

1

Dynamic Variables

Use curly braces like {name}, {email}, {message} in your body text. The backend replaces these with submitter data at runtime!

🚫 Custom Spam Blocklist

Filter incoming payloads against a blacklist of forbidden keywords (e.g., crypto, casino, free money). Any submission containing these words is flagged with +100 spam score and blocked.

🔑 API Key Expiration

Generate secure API keys with expiration (30/90/365 days or Never). Expired keys are rejected with 401 Unauthorized. All keys are HMAC-hashed for security.

💬 Slack & Discord Webhooks

Simply input your Slack or Discord webhook URL. The backend auto-structures notifications as Slack blocks or Discord embedded cards showing all submission details.

📅 Auto Data Retention

Set retention limits per form (30/60/90 days or Keep Forever). The backend auto-scans and purges expired records on new submissions. Zero cron configuration needed.

Developer Guide

API Examples

Complete examples for registering, creating forms, and submitting data.

Register an Owner Account

Create your first admin account to access the dashboard at /dashboard.

curl -X POST https://YOUR-WORKER.workers.dev/api/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"owner@example.com","name":"Owner","password":"change-this-password"}'

Create a New Form

Create a form endpoint with origin restrictions. Requires authenticated session cookie.

curl -X POST https://YOUR-WORKER.workers.dev/api/forms \
  -H 'Content-Type: application/json' \
  -b cookies.txt -c cookies.txt \
  -d '{"name":"Contact","allowedOrigins":"https://example.com"}'

Plain HTML Form

Drop this into any static website. The website honeypot field catches bots automatically.

<form method="POST" action="https://YOUR-WORKER.workers.dev/api/submit/endpoint_xxx">
  <input name="email" type="email" required />
  <textarea name="message" required></textarea>
  <!-- Honeypot spam trap (hidden from humans) -->
  <input name="website" tabindex="-1" autocomplete="off" hidden />
  <button>Send</button>
</form>

JavaScript fetch()

Works with React, Vue, Svelte, Astro, or any JavaScript frontend.

await fetch("https://YOUR-WORKER.workers.dev/api/submit/endpoint_xxx", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    email: "hello@example.com",
    message: "Hi from the frontend!"
  }),
});

cURL Command

Quick test from terminal.

curl -X POST https://YOUR-WORKER.workers.dev/api/submit/endpoint_xxx \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","message":"Hello from curl!"}'
Configuration

Environment Variables

Configure your Cloudflare Worker secrets and bindings.

Variable Required Description
AUTH_SECRET Required Long random secret for HMAC session & API-key hashing. Generate with openssl rand -hex 32.
RESEND_API_KEY Optional Enables email notifications only when configured. Leave blank to disable.
RESEND_FROM Optional Sender address for email notifications, e.g. FormForge <forms@example.com>.
DB Required Cloudflare D1 binding name. Configure as a D1 binding, not as a string secret.

⚠️ Do not set DATABASE_URL. FormForge uses Cloudflare D1 by default.

🚀 Deploy to Cloudflare in Seconds

Deploy your own serverless form backend — as easy as signing up for a commercial service.

How Deploy Works:

1
Cloudflare Creates a Fork

Cloudflare creates a copy of this repository in your GitHub account with all build configurations pre-wired.

2
Configure Project

Provide: Project name (e.g., "formforge"), Database name (e.g., "formforge-db"), and AUTH_SECRET (generate via openssl rand -hex 32 or jwtsecrets.com).

3
Build & Deploy

Cloudflare builds and deploys FormForge directly into your Cloudflare account (fully within the free tier). You get a unique URL like https://formforge.YOUR-SUBDOMAIN.workers.dev/dashboard.

💡 RESEND_API_KEY and RESEND_FROM are optional. Leave them blank if you don't need email notifications.

Manual Setup

🛠️ Alternative: Manual Setup

Prefer setting up manually instead of using the one-click deploy button?

Clone & Install

# 1. Clone & install
git clone https://github.com/SudhirDevOps1/FormForge.git
cd FormForge
npm install

# 2. Login to Cloudflare
npx wrangler login

# 3. Auto setup (interactive — asks app name, db name, auth secret)
npm run setup

Create D1 Database

Create a D1 database and paste the database_id into wrangler.jsonc.

npx wrangler d1 create formforge-db
# Copy the database_id output and paste it in wrangler.jsonc

Set AUTH_SECRET

Generate and store a strong secret key for session & API key hashing.

# Generate a random secret
openssl rand -hex 32

# Store it as a Cloudflare Worker secret
npx wrangler secret put AUTH_SECRET
# Paste your generated secret when prompted

Deploy to Cloudflare

Deploy your worker and access the dashboard.

npm run deploy

# After deploy, visit:
# https://YOUR-WORKER.workers.dev/dashboard

Pre-Flight

Production Checklist

Verify these before going live with FormForge.

  • ✅ The database_id in wrangler.jsonc is blank on purpose — Cloudflare creates the D1 database on first deploy.
  • ✅ Set a strong AUTH_SECRET in Cloudflare secrets (generate with openssl rand -hex 32).
